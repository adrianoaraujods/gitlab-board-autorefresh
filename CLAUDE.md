## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context only: one root `GLOSSARY.md` plus one root `docs/adr/`. Never create `GLOSSARY-MAP.md` or per-module glossaries or ADR folders. See `docs/agents/domain.md`.
